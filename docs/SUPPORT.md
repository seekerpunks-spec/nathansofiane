# CyberSeeker support — publication draft

For account access, purchase verification, privacy export/deletion or gameplay
issues, the final store listing must provide a publisher-owned support email and
public HTTPS page.

Include the following in a support request:

- public friend code (never a seed phrase or private key);
- approximate date/time and device model;
- the action that failed and any visible error code;
- purchase transaction signature only when purchase support requires it.

CyberSeeker support will never ask for a seed phrase or private key. The
publisher must replace this paragraph with verified contact and response-time
details before release.
