# Politique de confidentialité — brouillon produit

CyberSeeker utilise une adresse de wallet comme identifiant de jeu. Le serveur
stocke la progression, les inventaires, les achats vérifiés, les scores et des
événements techniques de gameplay nécessaires à l'exploitation du service.

Le jeu ne doit jamais journaliser de clé privée, seed phrase, signature complète,
JWT ou contenu du wallet non nécessaire. Les analytics utilisent l'horloge serveur
et des propriétés limitées aux actions de jeu. Aucune publicité n'est forcée.

Avant publication, ce brouillon doit recevoir les coordonnées de l'éditeur, les
durées de conservation, les sous-traitants réellement choisis, les procédures de
suppression/export et les mentions légales applicables aux territoires distribués.
