# Crypto collection artwork — R45

## Provenance

45 original scene illustrations delivered as five 3×3 atlases, generated with the built-in image generation tool (no API/CLI fallback). Native Godot card frames, names, rarity, quantity and exact SVG emblems are rendered separately. Atlas regions use an 8% safe inset per side; source PNGs remain untouched. WebP conversion only via tools/import_reference_art.gd, quality 96.

Runtime artwork: client/assets/generated/crypto_cards/. Source PNGs: art/crypto_cards/source/.

Logos: [spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons), svg/color, downloaded 2026-09-08. Upstream CC0-1.0 license is preserved at client/assets/crypto_logos/LICENSE.md. The artwork license does not imply project affiliation or ownership of underlying trademarks. Historical names/logos are intentional; no claim about present project status or financial value. SVGs are imported at 8× scale with mipmaps for readable detail views.
